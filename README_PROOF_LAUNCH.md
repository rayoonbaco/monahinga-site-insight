# Monahinga / Site Insight Proof Launch

This build is positioned as a proof-of-work preview, not a finished archaeology product.

## Demo path
1. Open START_SITE_INSIGHT.bat.
2. Open /launch.
3. Explain the thesis: information is abundant; the advantage is usable intelligence.
4. Start or open a run.
5. Show 3D terrain and terrain derivative layers.
6. Show archaeology synthesis as candidate-feature decision support.
7. Emphasize: candidate observations, not confirmed sites.

## Public claim
Monahinga turns selected terrain into visual evidence and expert-review questions using 3D terrain, terrain derivatives, and AI-assisted synthesis.

## Guardrails
- Do not claim confirmed archaeological sites.
- Do not claim expert replacement.
- Use “candidate feature,” “decision support,” “working preview,” and “proof of direction.”
